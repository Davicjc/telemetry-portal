Como configurar a RB750Gr3 do zero

RouterOS 6.49 · sem as-value
Copie a URL (e o Token, se ligado) na aba Configuração.
⚠️ Use o Winbox, NÃO o terminal. No terminal o ? abre a ajuda e quebra a URL. Configure por Winbox → System → Scripts (campo Source).
System → Scripts → “+” · Name sonda-telemetry · cole no Source: 
# === SONDA NOC AUDICOM — bateria completa (RouterOS 6.49, sem as-value) ===
# Latência: :execute joga o /ping num arquivo e extraímos o avg-rtt por texto.
:local probe "uberaba"
:local pingCount 5
:do { :execute script="/ping 198.18.255.45 count=5" file="pr1" } on-error={}
:do { :execute script="/ping 198.18.255.0 count=5" file="pr2" } on-error={}
:do { :execute script="/ping 8.8.8.8 count=5" file="pr3" } on-error={}
:do { :execute script="/ping 1.1.1.1 count=5" file="pr4" } on-error={}
:do { :execute script="/ping 57.144.232.1 count=5" file="pr5" } on-error={}
:local r1 [/ping 198.18.255.45 count=$pingCount]
:local r2 [/ping 198.18.255.0 count=$pingCount]
:local r3 [/ping 8.8.8.8 count=$pingCount]
:local r4 [/ping 1.1.1.1 count=$pingCount]
:local r5 [/ping 57.144.232.1 count=$pingCount]
:local l1 ((($pingCount - $r1) * 100) / $pingCount)
:local l2 ((($pingCount - $r2) * 100) / $pingCount)
:local l3 ((($pingCount - $r3) * 100) / $pingCount)
:local l4 ((($pingCount - $r4) * 100) / $pingCount)
:local l5 ((($pingCount - $r5) * 100) / $pingCount)
:local pppoe "down"
:foreach i in=[/interface pppoe-client find] do={ :if ([/interface pppoe-client get $i running] = true) do={ :set pppoe "up" } }
:local cpu [/system resource get cpu-load]
:local tot [/system resource get total-memory]
:local fre [/system resource get free-memory]
:local memp 0
:if ($tot > 0) do={ :set memp (($fre * 100) / $tot) }
:local dnsok 0
:do { :local x [:resolve "google.com"]; :set dnsok 1 } on-error={ :set dnsok 0 }
:local httpok 0
:do { /tool fetch url="http://clients3.google.com/generate_204" keep-result=no; :set httpok 1 } on-error={ :set httpok 0 }
:local rtt1 0
:local rtt2 0
:local rtt3 0
:local rtt4 0
:local rtt5 0
:do { :local c [/file get [/file find where name~"pr1"] contents]; :local a [:find $c "avg-rtt="]; :if ([:typeof $a]!="nil") do={ :local s [:pick $c ($a+8) [:len $c]]; :local m [:find $s "ms"]; :if ([:typeof $m]!="nil") do={ :set rtt1 [:pick $s 0 $m] } } } on-error={}
:do { :local c [/file get [/file find where name~"pr2"] contents]; :local a [:find $c "avg-rtt="]; :if ([:typeof $a]!="nil") do={ :local s [:pick $c ($a+8) [:len $c]]; :local m [:find $s "ms"]; :if ([:typeof $m]!="nil") do={ :set rtt2 [:pick $s 0 $m] } } } on-error={}
:do { :local c [/file get [/file find where name~"pr3"] contents]; :local a [:find $c "avg-rtt="]; :if ([:typeof $a]!="nil") do={ :local s [:pick $c ($a+8) [:len $c]]; :local m [:find $s "ms"]; :if ([:typeof $m]!="nil") do={ :set rtt3 [:pick $s 0 $m] } } } on-error={}
:do { :local c [/file get [/file find where name~"pr4"] contents]; :local a [:find $c "avg-rtt="]; :if ([:typeof $a]!="nil") do={ :local s [:pick $c ($a+8) [:len $c]]; :local m [:find $s "ms"]; :if ([:typeof $m]!="nil") do={ :set rtt4 [:pick $s 0 $m] } } } on-error={}
:do { :local c [/file get [/file find where name~"pr5"] contents]; :local a [:find $c "avg-rtt="]; :if ([:typeof $a]!="nil") do={ :local s [:pick $c ($a+8) [:len $c]]; :local m [:find $s "ms"]; :if ([:typeof $m]!="nil") do={ :set rtt5 [:pick $s 0 $m] } } } on-error={}
:local url "http://172.21.1.116:8080/api/probe?probe=$probe&pppoe=$pppoe&loss_bras=$l1&loss_core=$l2&loss_google=$l3&loss_cloudflare=$l4&loss_facebook=$l5&cpu=$cpu&mem_free=$memp&dns_ok=$dnsok&http_ok=$httpok&rtt_bras=$rtt1&rtt_core=$rtt2&rtt_google=$rtt3&rtt_cloudflare=$rtt4&rtt_facebook=$rtt5"
:do { /tool fetch url=$url http-method=post http-data="" keep-result=no } on-error={ :log warning "Sonda NOC: falha ao enviar" }
System → Scheduler → “+” · Interval 00:01:00 · On Event /system script run sonda-telemetry
Teste: selecione o script e clique Run Script.
✅ Bateria completa e testada nesta RB (RouterOS 6.49.20): Perda ×5, Latência ×5, PPPoE, CPU, Memória, DNS e HTTP. A latência sai sem as-value (que não existe no v6.49): o :execute grava o /ping num arquivo e extraímos o avg-rtt por texto.
⚠️ Edite sempre o script que o Scheduler roda (o do on-event=/system script run sonda-telemetry) — não crie um script novo à parte, senão o Scheduler continua rodando o antigo e nada muda. Confira com /system scheduler print detail.
