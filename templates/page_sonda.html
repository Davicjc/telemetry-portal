📡 Configuração da Sonda

A sonda (RB750Gr3) envia as métricas de experiência (PPPoE, latência, perda, DNS…) para o endereço abaixo. O portal recebe, guarda e mostra tudo aqui.

Quando uma sonda para de enviar ou o PPPoE cai, o portal avisa uma única vez no Telegram (e outra ao voltar, com o tempo fora) — se o Telegram estiver ativo na aba correspondente.

📖 Como configurar a RB750Gr3 do zero

Copie a URL e o Token aqui do lado — você vai colar os dois no script da RB.
Na RB, crie um script em /system script que coleta as métricas e envia via /tool fetch. Modelo pronto (ajuste os alvos e o nome da interface PPPoE): 
:local url "{{ cfg.ingest_url }}"
:local token "{{ cfg.token }}"
:local probe "uberaba"

# Alvos de teste (ajuste)
:local gw   "192.0.2.1"      ;# gateway/BRAS
:local core "198.51.100.1"   ;# IP do Core da Sede
:local dns  "1.1.1.1"

# PPPoE: troque "pppoe-out1" pelo nome da sua interface
:local pppoe "down"
:if ([/interface pppoe-client get [find name="pppoe-out1"] running] = true) do={ :set pppoe "up" }

# Ping: media de latencia (ms) e perda (%) em 10 pacotes
:local n 10
:local recv 0
:local sum 0
:foreach p in=[/ping $gw count=$n as-value] do={
    :if ([:typeof ($p->"time")] != "nothing") do={
        :set recv ($recv + 1)
        :set sum  ($sum + [:tonum ($p->"time")])
    }
}
:local lat 0
:if ($recv > 0) do={ :set lat (($sum / $recv) / 1000000) }   ;# ns -> ms
:local loss (100 - ($recv * 100 / $n))

# Monta o corpo e envia
:local body "{\"probe\":\"$probe\",\"token\":\"$token\",\"pppoe\":\"$pppoe\",\
\"metrics\":{\"latency_gateway_ms\":$lat,\"loss_pct\":$loss}}"
/tool fetch url=$url http-method=post \
  http-header-field="Content-Type: application/json" \
  http-data=$body keep-result=no
Alternativa simples (sem montar JSON): mande os campos na própria URL. Bom para começar rápido — o portal aceita qualquer campo numérico como métrica: 
/tool fetch keep-result=no http-method=post http-data="" \
  url="{{ cfg.ingest_url }}?token={{ cfg.token }}&probe=uberaba&pppoe=up&latency_gateway_ms=3.2&loss_pct=0"
Agende em /system scheduler para rodar a cada 30s: 
/system scheduler add name=sonda-telemetry interval=30s \
  on-event="/system script run sonda-telemetry"
Pronto. Em segundos os cards e gráficos abaixo começam a preencher. Se não aparecer, confira o token e se a RB alcança a URL (na RB: /tool fetch url="{{ cfg.ingest_url }}" ...).
