📡 Configuração da Sonda

A sonda (RB750Gr3) roda uma bateria de testes (perda, latência, jitter, DNS, HTTP, saúde) e envia para a URL abaixo. O portal recebe, mostra e alerta no Telegram por métrica.

Limites de alarme

Alertas no Telegram (uma vez por transição): sonda caiu/voltou, PPPoE, e cada teste ao passar/normalizar o limite (perda, latência, jitter, CPU, memória, DNS, HTTP).

📖 Como configurar a RB750Gr3 do zero

1
Copie a URL (e o Token, se ligado) ali do lado.
2
⚠️ Use o Winbox, NÃO o terminal.
No terminal o ? abre a ajuda e quebra a URL. Configure por Winbox → System → Scripts (campo Source).
3
System → Scripts → “+” · Name sonda-telemetry · cole no Source: 
# === SONDA NOC AUDICOM (RouterOS v6) — bateria de testes ===
:local probe "uberaba"
:local url "{{ cfg.ingest_url }}"
:local count 5
:local addrs {"198.18.255.45"; "198.18.255.0"; "8.8.8.8"; "1.1.1.1"; "208.67.222.222"}
:local names {"bras"; "core"; "google"; "cloudflare"; "dns2"}

:local qs ("probe=" . $probe)

# PPPoE (detecta a interface automaticamente)
:local pppoe "down"
:foreach i in=[/interface pppoe-client find] do={ :if ([/interface pppoe-client get $i running] = true) do={ :set pppoe "up" } }
:set qs ($qs . "&pppoe=" . $pppoe)

# Perda (confiável) + Latência/Jitter (best-effort via as-value)
:local i 0
:while ($i < [:len $addrs]) do={
  :local a [:pick $addrs $i]
  :local nm [:pick $names $i]
  :local recv 0; :local sum 0; :local mn 100000; :local mx 0; :local ok 0
  :do {
    :foreach p in=[/ping $a count=$count as-value] do={
      :set ok 1
      :local t ($p->"time")
      :if ([:typeof $t] != "nothing") do={
        :local ms ([:tonum $t] / 1000000)
        :set recv ($recv + 1); :set sum ($sum + $ms)
        :if ($ms < $mn) do={ :set mn $ms }
        :if ($ms > $mx) do={ :set mx $ms }
      }
    }
  } on-error={ :set ok 0 }
  :if ($ok = 0) do={ :set recv [/ping $a count=$count] }
  :local loss (100 - ($recv * 100 / $count))
  :local rtt 0; :local jit 0
  :if (($recv > 0) and ($sum > 0)) do={ :set rtt ($sum / $recv); :set jit ($mx - $mn) }
  :set qs ($qs . "&loss_" . $nm . "=" . $loss . "&rtt_" . $nm . "=" . $rtt . "&jitter_" . $nm . "=" . $jit)
  :set i ($i + 1)
}

# Saúde da RB (confiável)
:local cpu [/system resource get cpu-load]
:local tot [/system resource get total-memory]
:local fre [/system resource get free-memory]
:local memp 0
:if ($tot > 0) do={ :set memp (($fre * 100) / $tot) }
:local up ([:tonum [/system resource get uptime]] / 1000000000)
:set qs ($qs . "&cpu=" . $cpu . "&mem_free=" . $memp . "&uptime_s=" . $up)

# DNS e HTTP (teste de internet)
:local dnsok 0
:do { [:resolve "google.com"]; :set dnsok 1 } on-error={ :set dnsok 0 }
:local httpok 0
:do { /tool fetch url="http://clients3.google.com/generate_204" mode=http keep-result=no; :set httpok 1 } on-error={ :set httpok 0 }
:set qs ($qs . "&dns_ok=" . $dnsok . "&http_ok=" . $httpok)

# Envio (tudo na URL — o v6 não manda corpo em POST)
:do { /tool fetch url=($url . "?" . $qs) http-method=post http-data="" keep-result=no } on-error={ :log warning "Sonda NOC: falha ao enviar" }
Token ligado? Adicione :set qs ($qs . "&token=SEU_TOKEN") antes do envio.
4
System → Scheduler → “+” · Interval 00:01:00 · On Event /system script run sonda-telemetry
5
Teste: selecione o script e clique Run Script.
⚠️ Latência/Jitter usam as-value (RTT em ms). Se aparecerem 0 ou valores gigantescos, é a conversão de unidade do seu RouterOS — me manda um exemplo que eu ajusto o divisor. Perda, PPPoE, CPU, Memória, DNS e HTTP são 100% confiáveis.
